Snelle Gids: Ubuntu Commando's

Bestands- en Mapbeheer

  • ls Toont de inhoud (bestanden en mappen) van de huidige map.
  • cd [mapnaam] Verandert de huidige map (Change Directory). Gebruik cd .. om een map omhoog te gaan.
  • pwd Toont het volledige pad van de map waarin je je nu bevindt (Print Working Directory).
  • mkdir [mapnaam] Maakt een nieuwe map aan (Make Directory).
  • rm [bestandsnaam] Verwijdert een bestand (Remove). Gebruik rm -r [mapnaam] om een map en de inhoud te verwijderen.
  • cp [bron] [doel] Kopieert een bestand of map (Copy).
  • mv [bron] [doel] Verplaatst of hernoemt een bestand of map (Move).

Systeembeheer

  • sudo [commando] Voert een commando uit met administrator- (root) rechten. Essentieel voor installaties of systeemwijzigingen.
  • top Toont een live overzicht van actieve processen en systeembronnen (CPU, RAM). Druk op 'q' om te stoppen.
  • df -h Toont het schijfgebruik in een leesbaar formaat (Disk Free).
  • reboot Herstart het systeem (vereist meestal sudo).
  • shutdown now Sluit het systeem onmiddellijk af (vereist meestal sudo).

Pakketbeheer (Software)

APT is het systeem van Ubuntu om software te beheren.

  • sudo apt update Ververst de lijst van beschikbare softwarepakketten van de servers.
  • sudo apt upgrade Installeert de nieuwste versies van alle softwarepakketten die al op je systeem staan.
  • sudo apt install [pakketnaam] Installeert een nieuw softwarepakket (bijv. sudo apt install vlc).
  • sudo apt remove [pakketnaam] Verwijdert een softwarepakket.
